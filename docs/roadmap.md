# 內容擴充路線圖

目標：讓網站達到申請學校補助的完成度。每一項都要符合專案慣例：史實有出處（`src/data/sources.js`）、未查證的年份要標示、情境重建要標「歷史情境重建」、新內容要有單元測試並更新 README。

進度標記：☐ 未開始　◐ 進行中　☑ 完成

## 第 0 階段｜共用基礎（新內容都會用到）

- ◐ 店家資料欄位：台語讀音（`taiwanese`）已完成（9 個有辭典詞條的詞）；英文摘要 `summaryEn` 已有 5 家（林復振、新芳春茶行、江山樓、波麗路、稻舍），章節 `leadEn` 與其他店家待補；文獻授權欄位 `license` 尚未做（授權頁目前依出版單位說明）。
- ☑ 授權頁：文字與插圖採 CC BY-NC-SA 4.0；列出所有文獻；程式碼授權待使用者決定；目前沒有外部老照片，日後加入時逐張標示（`src/data/licenses.js`）。
- ◐ 英文介面：開場、HUD、店家名錄、設定、總覽標題與授權頁標題已完成，5 家店有英文摘要；其餘店家摘要、任務提示、年代名稱與章節全文待補。

## 第 5 階段｜清末開街

- ✖ 林藍田／林益順（1851）：**資料不足，不做**。「1851 年建店屋三幢」只有國家文化記憶庫一條來源不明的說明（該筆「創作時間」欄還寫 1815，自相矛盾），其餘媒體、部落格互抄；學術與古蹟公告查無，與 1853 頂下郊拚的關係沒有文獻。紀錄見 `docs/research/lin-yi-shun.md`。
- ☑ 霞海城隍廟（1859）：章節已寫、開放探索（「港口商街」的文化據點 `xia-hai-cheng-huang`，建築用 `temple` 原型、情境示意）。祭祀飲食無出處不寫；古蹟級別沿革標「待核」。測試 `tests/xiaHai.test.js`。原查證備註：文獻已查、待寫章節。創建、地址、市定古蹟字號、迎城隍流程、月老（1971 增祀）足夠；**祭祀飲食出處不足**，章節別寫供品；古蹟官方原頁未能核對。紀錄見 `docs/research/xia-hai-cheng-huang.md`。
- ☑ 乾元藥行：章節已寫、開放探索（「酒樓繁華」的文化據點 `qian-yuan-yao-hang`，立面為歷史情境重建）。創立年 1896／1875 並列；門牌、建築年代與文資身分不寫成事實。測試 `tests/qianYuan.test.js`。原查證備註：文獻已查、待寫章節。創立年份兩說（臺史所採 1896，另有 1875），創辦人張清河與歷代經營者足夠；門牌、建築年代、登錄、現況不足，章節要標示。紀錄見 `docs/research/qian-yuan-yao-hang.md`。

## 第 6 階段｜庶民生活

- ☑ 慈聖宮廟口：章節已寫、開放探索（`ci-sheng-gong` 用 `eras` 分年代：酒樓繁華／摩登是文化據點「廟與廟埕」，庶民生活是「廟口小吃」＋排骨湯、肉粥、豬腳麵線、四神湯的圖鑑（歷史情境重建、只寫做法特色），老屋新生只寫現況）。沒有新的 3D 攤位（廟埕已被四攤佔滿）。不寫具名老店、攤主與各攤年份；廟的沿革年份並列、「民國 50 年間」標待核。測試 `tests/ciShengMiaokou.test.js`。原查證備註：只能做情境示意攤位（不用現代店名）；具名老店與日治時期廟口資料不足、不做。紀錄見 `docs/research/ci-sheng-gong-miaokou.md`。
- ✖ 林合發油飯（1894）：同一家店的五個年代（做法同稻舍）。資料不足，不做五個年代：1894 創立只有食記說法，日治、戰後、店址皆查無，且是市場攤位非獨立店屋。僅「2000 後現況＋做法」可部分做，清末一小段標待核。紀錄見 `docs/research/lin-he-fa.md`。
- ✖ 意麵王（1938）：**資料不足，不做**。賣乾意麵與餛飩湯、不是米苔目，不放進米苔目主題；「80 年」是食記說法，1938 只是推算，創辦人、傳承、戰前戰後皆查無，門牌 202／204 號並列。紀錄見 `docs/research/yi-mian-wang.md`。
- ◐ 呷二嘴（1954）：已查證，**部分可做**。米苔目主題的 `versions` 年代位置已滿（廟埕攤是不具名情境示意、永樂米苔目占現代），只能放 `related` 當現代相關店家、寫現況與做法；1954、創辦人、世代、早期攤位位置標待核，查無與意麵王或慈聖宮廟口的關係，不寫「米其林推薦」。紀錄見 `docs/research/xia-er-zui.md`。
- ◐ 迪化街年貨大街（1996 起）：已查證，**部分可做**。市府新聞稿與 1995 報導支持「1996 年、市府與商家合辦、構想由民間迪化街工作室提出」；主辦局處、實際日期與範圍、更早南北貨史標待核，不寫「百年傳統」。「南北貨 → 年貨大街」的敘事章節建議用 Fable。紀錄見 `docs/research/dihua-nianhuo.md`。
