# 有記名茶 `you-ji` 室內設計（第 11 階段第 1 段，2026-11-02）

四個年代：酒樓繁華、摩登、庶民生活、老屋新生。二樓清源堂要能上樓（使用者 2026-11-02 決定）。
仍在營業（重慶北路二段 64 巷 26 號）：**只依官網與公開報導的照片建模，不寫店家沒有公開的經營細節，不把虛構對白安在王家人身上**；人物不具名。

## 0. 摘要

- 現址的室內有足夠的公開照片（官網門市頁 12 張、《臺灣工藝》80 期、微笑台灣），**老屋新生可以依照片做**：一樓門市（弧形木櫃台、木格抽屜茶櫃、圓茶罐、金字匾）→ 木格屏風門 → 後面的焙籠間（焙窟、焙籠、炭焙工具、風選機）；二樓清源堂（木桁架、紅毯矮舞台、黑雕花屏風、「御前清客」匾、牆上的南管樂器）。
- 庶民生活（1949 年遷入現址之後）用同一套格局、擺設回到「精製茶廠」：二樓是揀茶樓（約四十名女工）。
- **酒樓繁華、摩登兩個年代有記不在這裡**（茶行在民生西路口、精製廠在建昌街 11 號，1949 年才遷現址），格局全部是「歷史情境重建」：用同一棟外殼，擺設照日治時期精製茶廠的一般情形；店內加一個提醒熱點（第 6 節）。
- 新器物 4 件（2 件跨店共用）：嘜頭 `mark-stencil`、稻殼焙窟 `husk-ash-pit`、風選機 `winnowing-machine`（與新芳春共用）、南管樂器 `nanguan-instruments`。沿用：揀茶竹淺盤 `tea-sorting-tray`、焙籠 `roasting-basket`、磅仔 `platform-scale`、算盤 `abacus`、包種茶罐 `baozhong-tin`。
- 要決定：清源堂的匾「御前清客」要不要照抄、南管樂器畫幾件、1949 以前的提醒熱點怎麼寫。

### 1.2 《臺灣工藝》第 80 期 pp.46–51（PDF 實際讀到；已有 `ntcri-80-wangtea-lab`）

- p.48 原文：「沒有電窯的時代，是將已炭化的黑色稻殼點火燒成白灰做為熱源，放在深達58公分的炭焙窟中，上方再置焙籠，日夜不休烘焙20天。這項工作現在多以電窯來取代，但當年使用的焙籠間、炭焙窟和工具等均保存於比鄰的有記名茶老店面中，設置了說明牌並安排專人導覽」；同頁：對街洗衣店會把衣服送來焙籠間烘乾。

### 2.1 共用外殼（兩層，要上樓）

地段 x=11.6 北側，6 × 11 m，兩層。拆成專用樣式 `you-ji`＋variant，立面依 IMG_1286（紅磚、一樓洗石子橫帶、二樓 7 扇直長格子窗；現有 `baroque` 的山牆保留，因為街上的立面本來就是示意）。

```
shell: {
  half: 3.0, depth: 11, wallT: 0.3, groundH: 3.3, ceiling: 2.95, walkD: 1.7,
  room: { minX: -2.65, maxX: 2.65, minZ: -10.4, maxZ: -0.34 },
  floor2: { y: 3.3, ceiling: 2.6, room: { minX: -2.65, maxX: 2.65, minZ: -10.4, maxZ: -1.0 } },
}
```

多樓層的做法照稻舍（`riceAndShineSecondFloor.js`）與爐鍋咖啡的 `staircase`：木樓梯靠右牆（+x）沿後段往 -z 爬升，樓梯井 1.0 × 3.2 m（本地 x 1.6 … 2.6，z -9.6 … -6.4），平台在二樓後端，二樓的 `levels: [0, 1]` 可行走範圍寫在同一份清單；樓梯下方是儲物，`block: true`。清源堂照片裡「左側有樓梯口與深色布簾」，和這個位置相容（從舞台看去是左側）。

一樓的隔間牆（partition）把門市與焙籠間分開，中央留門；照片裡門市後方正是「木格屏風門通往廠區」，所以 `partitionWindows: true`、門用木格屏風。

## 5. 入口、碰撞、鏡頭與效能

- 入口：中央雙開木門；老屋新生 `frontPanels: 'open'`（櫥窗下牆），其他年代門板或捲門。
- 碰撞：一樓三段加二樓；樓梯井 `levels: [0, 1]` 的矩形照爐鍋咖啡 `stairsPart` 的寫法；二樓的可行走範圍扣掉舞台、屏風、桌子；焙窟的 `pitStrip` 是整條障礙物，走道 ≥ 0.9 m。
- 鏡頡：二樓天花 2.6 m，跟隨鏡頭 `maxHeight` 2.2；樓梯段用 `followAreas` 平滑升降（稻舍已有）。木桁架只畫在二樓天花（精緻畫質才畫斜撐）。
- 效能：外殼拆專用樣式，四個年代的 `smoothBaseline.json` 更新；二樓只在走上樓梯時載入（`loadRadius` 以樓梯口為中心）。器物每層約 10–14 件。

## 6. 要使用者決定的事

1. **「御前清客」匾**：照片裡清源堂舞台上方有這塊匾，是南管館閣的慣用名號，但本站沒有文字出處說明它的由來。建議照抄四個字（照片可見），器物文字只說「照片可見」、不解釋由來。
2. **南管樂器畫幾件**：照片可辨 4 件，名稱有兩件不確定（三絃或二絃、月琴形）。建議畫 4 件，器物文字標 pending。
3. **1949 年以前的提醒熱點**：酒樓繁華、摩登的店內加一個熱點「這個年代有記不在這裡」（章節已寫），還是只靠 `note`？建議加熱點，一句話＋出處。
4. **焙窟數量**：照片只見 3–4 個，官網「約 40 個焙籠」。建議畫 10 個坑，對白說四十。
5. **商標**：英文、泰文商標查無照片，摩登年代的標籤只寫 FORMOSA（故事頁有「FORMOSA／有記選庄」木箱），泰文不畫。
