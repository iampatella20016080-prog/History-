# 新芳春茶行 `xin-fang-chun` 室內設計（第 11 階段第 1 段，2026-11-02）

三個年代：摩登（1934 落成）、庶民生活、老屋新生（茶葉故事館）。二樓揀茶間要能上樓（使用者 2026-11-02 決定）。
不是營業中的店家（市定古蹟、免費開放），可以依公開照片完整重建；三樓是王家起居與公媽廳，**不開放、不畫祭祀細節**。

## 0. 摘要

- 11 棟裡照片最齊的一棟：Wikimedia Commons「Category:Sin Hong Choon」約 93 張（氏子，CC BY-SA 4.0，2022／2025），《臺灣工藝》77 期兩篇（含修復專文），子代理實際看過 20 多張。一樓正廳、樓梯、天井、焙籠間、加工廠（風選機、切茶機、抖篩機、磅秤、天軸）、二樓都有照片。
- 老屋新生依照片做故事館；摩登（1934–1945）與庶民生活用同一格局，擺設回到營運中的茶行（有文獻的格局：一樓正廳茶行、帳房、銷售，後進精製倉庫與加工廠；二樓揀茶間、辦公室、會客廳；三樓住家與公媽廳）。
- 12 m 進深放不下「三進」：壓成**前進（正廳）→ 天井 → 後進（焙籠間＋加工廠）**兩段加一個天井，並寫明壓縮。
- 新器物 3 件（風選機與有記共用，寫在 `interior-you-ji.md`）：切茶機 `tea-cutter`、優良茶比賽獎狀 `tea-award-certificate`、外銷鐵罐 `export-tea-tin`。沿用：焙籠 `roasting-basket`、炭焙火坑 `charcoal-pit`（補一層）、揀茶竹淺盤、包種茶罐 `baozhong-tin`、磅仔 `platform-scale`、算盤 `abacus`、四方包 `square-packet`。
- 要決定：焙籠坑畫幾個（「數十個」對「約一百個」）、三樓要不要畫樓梯口、老屋路線的人物移不移進屋。

### 1.1 文獻（已有出處：`nchdb-xinfangchun`、`tcmb-xinfangchun`、`ntcri-77-xinfangchun`、`ntcri-77-xinfangchun-restoration`、`ltn-xinfangchun-2015`、`pts-xinfangchun-2016`、`zsdo-xinfangchun-2020`、`travel-taipei-xinfangchun`、`epochtimes-xinfangchun-2022`、`nmth-xfc-tea-tin`）

- 《臺灣工藝》77 期 p.53 原文：「不同於一般『單開間』店屋，這棟茶行由三個單間併連，樓高三層，深度也有三進，總樓地板面積為492坪」「走進一樓檜木大門，挑高的正廳是茶行、帳房與銷售空間，後進則是精製茶的倉庫與加工廠；二樓是揀茶間、辦公室，以及完整保留1930年代風格的會客大廳；三樓則是王家仍在使用之私人家居空間及公媽廳等。」
- p.54：「經過天井，走到一樓後進的『茶葉故事館』，先是一整面牆上的臺灣茶業發展史時間表，往後走即為……『焙籠間』……裡頭保留有數十個焙茶用的『焙籠坑』以及竹籠等工具；另一個空間則是精製茶加工廠和倉庫區，保留了乾燥機和風選機等機具……牆上貼有繪製焙茶步驟的木烙畫」

## 2. 各年代格局

### 2.1 外殼：三層、三開間，壓縮成兩段加天井

地段 x=-27 南側，7.2 × 12 m，三層（`tea-mansion`，`builders/specials.js`）。建築外觀已有（三開間、三層、水平帶狀女兒牆與三角形山頭）；室內做一樓與二樓，三樓只有樓梯口（門關著，熱點「三樓是王家住家與公媽廳，不開放」）。

```
shell: {
  half: 3.6, depth: 12, wallT: 0.3, groundH: 3.6, ceiling: 3.3, walkD: 1.7,
  room: { minX: -3.25, maxX: 3.25, minZ: -11.4, maxZ: -0.34 },
  courtyard: { minX: -1.2, maxX: 1.2, minZ: -6.6, maxZ: -4.6 },   // 天井（日月雙井壓成一井）
  floor2: { y: 3.6, ceiling: 2.9, room: { minX: -3.25, maxX: 3.25, minZ: -11.4, maxZ: -1.0 } },
}
```

- 一樓前段（z -0.34 … -4.6）：正廳＝茶行、帳房、銷售。洗石子圓柱兩根（x ±1.8，z -2.4）、方柱靠牆、木樑天花、玻璃吊燈。右後方木樓梯（Interior-08：樓梯在正廳右後）。
- 天井（z -4.6 … -6.6）：中央 2.4 × 2.0 m 露天，三面紅磚牆、二樓一排白框格子窗、頂部洗石子花瓶欄杆、馬賽克拼花地坪；兩側是穿心廊（走道寬 1.0 m）。天井不可走（低欄杆 `block: true`）或可走（地坪）——建議可走，天光用 `windowLit`。
- 一樓後段（z -6.6 … -11.4）：左半焙籠間（磚砌低台、兩列交錯的坑、竹焙籠、木烙畫、長柄工具），右半加工廠（風選機、切茶機、抖篩機、磅秤、天軸與皮帶輪）。
- 二樓：前段揀茶間（石磚地），中後段辦公室／會客廳（紅地磚＋木地板分段），天井口有欄杆。樓梯口在右後。
- 三樓：樓梯上到二樓後，往三樓的梯段用門擋住（`block: true`）。

寫明：真實建築縱深三進、約 492 坪，本站壓成 12 m 兩段一井，是示意。

## 5. 入口、碰撞、鏡頭與效能

- 入口：檜木雙開門，`frontPanels: 'open'`（兩側高大格子窗）。
- 天井：`shopInterior.js` 目前只有一道 partition，天井要加 `courtyard` 支援（兩道牆各留穿心廊）或用器物圍出。建議在模組加 `courtyard: { rect, walkable: true }`，產生三面磚牆、二樓欄杆、天光。稻舍已有天井的做法（`riceAndShineInterior.js` 的 courtyard），可以沿用。
