# 英文譯名表

英文版全站統一用這份譯名。新增詞條時照「官方英文名 → 通行拼音 → 拼音加說明」的順序決定；每批翻譯開始前先讀這份，結束時把新詞補進來。測試 `tests/englishGlossary.test.js` 會檢查英文裡不出現表中標為「禁用」的寫法。

## 原則

1. **拼音**：現代地名、人名用漢語拼音（Dadaocheng、Dihua Street），不加聲調符號。台語人名若有通行寫法（Lee Chun-sheng 李春生、Huang Yu-chieh 黃玉階）則依通行寫法；本表列出的就是全站用法，其餘人名用漢語拼音、姓在前（Chen Cixu）。
2. **店名**：有官方英文名的用官方名（Bolero、Action! Bar）；沒有的用拼音加說明，第一次出現寫成「Jiangshanlou (江山樓), the Jiangshan Pavilion restaurant」，之後只寫拼音。
3. **清代文獻**：引用當時的西文拼法時附上，並注明出處（Twatutia 見 Dodd《Journal of a Blockaded Resident in North Formosa》1888；Bangka 見同期領事報告）。現代敘述用現代拼音。
4. **原文保留**：招牌圖集上的字、古文原文、台語讀音（台羅）不翻；古文另附英譯並標「Translation by this site」。近代歌詞、小說不翻原文，只寫篇名、背景與改寫。
5. **三種標示**：「有出處」＝ Sourced；「坊間傳說」＝ Folk tale；「虛構對白」＝ Fictional dialogue。「歷史情境重建」＝ Reconstructed historical scene。

## 禁用寫法

- 「Taibei」「Tai-pei」（用 Taipei）
- 「Dadaocheng Street」（沒有這條街，用 Dadaocheng 或 Dihua Street）
- 「Harbor」（全站用英式 harbour）
- 「Twatutia」只在清代語境使用（現代敘述寫 Dadaocheng）
