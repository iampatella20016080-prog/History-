# 環境音：音檔來源、授權與年代依據（第 9 階段）

## 來源與授權

**7 個音檔全部是 CC0 或公有領域的真實錄音剪成的循環。**（原本 11 個，碼頭吆喝、街上人聲、廟埕叫賣、機車四個依使用者決定移除，不用其他聲音補上；見文末〈移除的聲音〉。） 每個檔案的來源網址、作者、授權、原始檔名、剪輯段落與處理方式記在
`src/audio/ambienceCredits.js`，人看的版本是 `public/audio/ambience/CREDITS.md`（由 `node tools/music/write_ambience_credits.mjs` 產生，
測試檢查兩者一致、每個音檔都有記錄、授權只能是 CC0 或公有領域）。

選擇原則：

- 只用 **CC0**（Freesound 的 CC0 篩選）或**公有領域**（Wikimedia Commons 上已有授權標示、且作曲者與演奏者都已過世很久的 78 轉唱片轉錄）。
- CC-BY 等需要署名的授權先不用（候選列在下面，等使用者決定）；BBC Sound Effects 是非商用條款，不用。
- 下載的檔案先放在工作目錄外的隔離資料夾，確認授權頁與內容（頻譜、響度、語音辨識）後才剪輯輸出到 `public/audio/ambience/`。
  原始錄音不放進專案（太大）；`tools/music/build_ambience_real.py` 記著每個來源的下載網址，可以重新下載、重新剪輯（結果固定）。
- Freesound 的原始 WAV 需要登入，所以用免登入的高品質預覽 MP3（128 kbps）當剪輯來源；CC0 不限制使用哪一個版本。

剪輯只做：剪段落、濾波（模擬距離、喇叭留聲機或調幅收音機的頻寬）、音量、峰值限制、淡入淡出、等功率交叉淡化與混音，**沒有加入合成的聲音**。
循環接點：取「循環長度＋2 秒」的片段，把多出的 2 秒交叉淡化疊回開頭；鈴聲、出力聲這類事件型的聲音放在循環中間，接點落在無聲處。
輸出後解碼檢查：接點的樣本跳動不大於前後 0.5 秒內相鄰樣本差的第 99 百分位（沒有喀聲），並比較 y[t] 與 y[t + 循環長度] 只剩 MP3 編碼誤差。

## 聽感與驗證的限制（誠實標示）

- **沒有人耳試聽過剪輯結果**，也**沒有在 iPad 實機試聽**；只用頻譜圖、響度量測、接點量測，以及內建瀏覽器確認能解碼與播放。音量比例、混音平衡、循環的聽感都要再用耳朵調整。
- 人聲是否「聽不出清楚的語言」用 Whisper（small）語音辨識檢查：木柵市場、出力悶喊、收音機底噪都沒有辨識出可信的句子（只有雜訊幻覺）；前兩者後來已移除。這是自動檢查，不等於人耳確認。
- 有兩個候選因為含清楚的談話而排除：martian 的香港西貢木划艇錄音（船上有人談話）、didierwei 的臺北巷弄夜間錄音（開頭有錄音者的口述標記）。

### 合成備援（`public/audio/ambience/synth/`）

原本 `tools/music/generate_ambience.py` 合成的 11 個示意音（約 1.0 MB，沒有第三方素材）保留作備援：某個真實錄音下載或解碼失敗時，
只有那個聲音改用合成音，循環長度跟著換。保留的理由：備援只在失敗時才下載，平常不佔流量；部署漏檔或某個瀏覽器解碼失敗時，街上不會整個安靜。

## 各年代的聲音

| 年代 | 聲音（位置） |
| --- | --- |
| 港口商街 | 河水（河岸）、船槳與水花（河岸） |
| 酒樓繁華 | 遠處的鑼鼓（街東側，由遠而近）、遠一點的河水 |
| 摩登大稻埕 | 腳踏車鈴（整條街）、留聲機（街屋列中段近處）、遠一點的河水 |
| 庶民生活 | 三輪車（整條街）、收音機（街屋列中段近處）、遠一點的河水 |
| 老屋新生 | 河岸廣場的河水（只有這一個） |

位置相關的聲音只用 Web Audio 的 gain 依人物到錨點的距離調整（內圈全音量、外圈 0，之間平滑下降），不使用 PannerNode；
同時播放的聲軌上限 4 個（含淡出中的），其餘等有空位。年代轉場時開始就淡出（0.6 秒）、街景換上後淡入（1.4 秒）。
錨點座標在 `src/audio/ambienceCore.js`，是依街道座標估的位置，不是史料。真實錄音的響度和原本的合成音一致（方均根 -22 dBFS），
所以音量比例沿用，只有三輪車（錄音有輪子喀噠的尖峰、平均音量較低）從 0.7 調到 0.95。

## 年代正確性

| 聲音 | 年代 | 判斷與待核 |
| --- | --- | --- |
| 港口商街（1853–1895） | 不放任何機械聲、電聲、車鈴 | 只有河水與划槳。 |
| 遠處的鑼鼓 | 酒樓繁華（1895–1930） | 只是「街上有鑼鼓」的氛圍示意（香港醒獅）；**沒有宣稱是北管、南管或任何特定曲牌**，實際演出的樂器與曲目**待核**。 |
| 腳踏車鈴 | 摩登（1930–1945） | 與 `docs/research/era-street-props.md` 一致：1930 年代後期本島人擁有逾 35 萬台腳踏車。車鈴是英國傳統機械鈴，音色為示意。 |
| 留聲機 | 摩登（1930–1945） | 波麗路西餐廳 1934 年開業時以 78 轉電唱機播古典樂（`docs/research/bolero.md`，B4），所以用古典樂的 78 轉唱片；用的是 1923 年的公有領域唱片，不是當年實際播放的那一張。 |
| 三輪車 | 庶民生活 | 與 `era-street-props.md` 一致：戰後取代人力車，臺北 1968 年全面禁行（另說 1960 年起消失，待核）。聲音用腳踏車與日本車鈴組成。 |
| 收音機 | 庶民生活（1945–1980） | 臺灣的廣播自日治時期就有（1920 年代起），1945–1980 家庭與商店收音機普遍，是一般認知，**出處待核**。播放內容用公有領域的古典樂唱片代替，沒有任何電台節目或近代歌曲。 |

## 之後可以做的

- 用耳朵試聽（桌面與 iPad 實機），調整各聲音的 `gain`、距離半徑與剪輯段落。
- 決定上面的 CC-BY 候選要不要用（要用的話，網站上需要有署名頁）。
- 找臺灣的老錄音：國家文化記憶庫、國家電影及視聽文化中心、中研院的唱片數位典藏中，若有明確標示公有領域或 CC0 的叫賣、廣播、廟會錄音，可以取代情境示意。
- 室內另做環境聲（目前走進店裡仍聽得到街上的聲音，只是依距離與人物位置調整）。
