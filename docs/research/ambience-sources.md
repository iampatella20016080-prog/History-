# 環境音：音檔來源、授權與年代依據（第 9 階段）

## 來源與授權

**11 個音檔全部是自己用程式合成的，沒有下載或使用任何第三方音檔、取樣或錄音。**
產生程式是 `tools/music/generate_ambience.py`（numpy 濾波雜訊與加法合成，ffmpeg 轉 MP3），隨專案原始碼一起提供；
音檔是這個專案的原創產物，沒有第三方授權問題，授權跟隨專案本身。

決定全部自己合成的原因：Freesound 等站的下載需要登入帳號，且逐檔的授權標示（CC0、CC-BY 需署名、非商用）要逐一核對；
補助申請的作品要能商用或公開，授權不確定的一律不放。BBC Sound Effects 是非商用條款，不用。
之後若要換成真實錄音，只接受 CC0 或明確可商用且已逐檔記錄作者與網址的來源，並更新這份文件。

## 聽感的限制（誠實標示）

- 合成音是「示意」：河水、人聲、吆喝、鑼鼓、鈴聲、引擎聲都是濾波雜訊或共振峰合成，聽起來比真實錄音單薄；「人聲」只有母音節奏，沒有任何語言內容。
- 沒有宣稱還原當年的實際聲音，也沒有使用任何歌曲、唸謠、廣播內容或曲牌。
- **目前沒有在 iPad 實機試聽**；音量比例、混音平衡與循環接縫（已在桌面瀏覽器確認能解碼、循環參數正確）都需要用耳朵再調整。

## 各年代的聲音

| 年代 | 聲音（位置） |
| --- | --- |
| 港口商街 | 河水（河岸）、碼頭吆喝（河岸／棧橋）、船槳與水花（河岸）、輕的街上人聲（底噪） |
| 酒樓繁華 | 人聲（底噪）、遠處的鑼鼓與絃音（街東側，由遠而近）、遠一點的河水 |
| 摩登大稻埕 | 人聲、腳踏車鈴（整條街）、留聲機（街屋列中段近處）、遠一點的河水 |
| 庶民生活 | 人聲、攤販叫賣（慈聖宮廟埕）、三輪車（整條街）、收音機（街屋列中段近處）、遠一點的河水 |
| 老屋新生 | 人聲、機車（整條街）、河岸廣場的河水 |

位置相關的聲音只用 Web Audio 的 gain 依人物到錨點的距離調整（內圈全音量、外圈 0，之間平滑下降），不使用 PannerNode；
同時播放的聲軌上限 4 個（含淡出中的），其餘等有空位。年代轉場時開始就淡出（0.6 秒）、街景換上後淡入（1.4 秒）。
錨點座標在 `src/audio/ambienceCore.js`，是依街道座標估的位置，不是史料。

## 年代正確性

| 聲音 | 年代 | 判斷與待核 |
| --- | --- | --- |
| 港口商街（1853–1895） | 不放任何機械聲、電聲、車鈴 | 只有河水、人聲、划槳與吆喝。碼頭實際的叫賣內容、號子、船工用語查無，所以只用無詞的音高輪廓，不寫成特定喊聲。 |
| 遠處的鑼鼓與絃音 | 酒樓繁華（1895–1930） | 只是「酒樓、宴席有樂聲」的氛圍示意；**沒有宣稱是南管或任何特定曲牌**，音階用五聲，實際演出的樂器與曲目**待核**。 |
| 腳踏車鈴 | 摩登（1930–1945） | 與 `docs/research/era-street-props.md` 一致：1930 年代後期本島人擁有逾 35 萬台腳踏車。車鈴音色為示意。 |
| 留聲機 | 摩登（1930–1945） | 1930 年代臺灣已有留聲機與唱片業，是一般認知，**本專案尚未查到可引用的出處，待核**（可查臺灣唱片業、流行歌曲史的文獻）。樂句是自編的五聲音階片段，不是任何一首歌，避開近代歌曲的著作權。 |
| 攤販叫賣 | 庶民生活（1945–1980） | 廟口小吃攤的情境見 `ci-sheng-gong-miaokou.md`；叫賣是無詞示意。 |
| 三輪車 | 庶民生活 | 與 `era-street-props.md` 一致：戰後取代人力車，臺北 1968 年全面禁行（另說 1960 年起消失，待核）。鈴聲為示意。 |
| 收音機 | 庶民生活（1945–1980） | 臺灣的廣播自日治時期就有（1920 年代起），1945–1980 家庭與商店收音機普遍，是一般認知，**出處待核**。只有節奏，沒有播放任何節目、歌曲或語言內容。 |
| 機車 | 老屋新生（2000–現在） | 臺灣的機車 2000 年後是主要交通工具之一，沒有年代疑義。只用在這個年代，不放進其他年代（庶民生活後期雖已有機車，但街景沒有機車模型，所以不放）。 |
