# 在地經營者群像（第 8 階段 C）：素材盤點與取捨

日期：2026-10-25。本紀錄不是新的文獻查證，而是盤點專案裡**已有出處**的經營者資料，決定庶民生活（1945–1980）與老屋新生（2000–現在）兩章群像各寫什麼、不寫什麼。各店的查證細節見同資料夾裡各自的研究紀錄。

## 為什麼是群像，不是人物

- 庶民生活：黃玉階的活動全在 1850–1918（見 `huang-yu-jie.md`），人物不在本年代；其他候選人查無。
- 老屋新生：現在營業中的店家不宜寫成歷史人物。
- 使用者同意兩個年代改做「在地經營者群像」，由現有店家章節承擔；只寫文獻記下的行動、傳承與轉變，不評價、不推論動機。
