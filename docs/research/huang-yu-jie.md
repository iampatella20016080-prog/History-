## 4. 「議員」：查無

任務提到「臺北市議員」。ncl、tcmb、merit、NCU2024 摘要**都沒有**黃玉階任議員（市議員、協議會員）的記載；他 1918 年即逝世，早於 1946 年起的戰後地方自治選舉，「臺北市議員」在時間上不可能。**不寫**。

## 5. 文史館與人物的關係

- 《人間福報》（2026）明寫：黃玉階「在大稻埕開設一間名為『元珍』（耆老口述稱源珍，帳冊寫元珍）的豆醬店」，百年前的元珍豆醬店如今是黃玉階文史館。
- 黃瑤琨 1914 年畢業後回元珍豆醬店開設醫館，故店面前為豆醬店、後為醫館｜merit（單一）。**黃瑤琨與黃玉階的親屬關係原文摘要未說明，專案沒有此人資料，不寫親屬關係。**
- **人物與老屋的關係只有一篇 2026 年報導**；ncl、tcmb 只寫「醬菜坊／醬菜業」，沒有商號名「元珍」，也沒有說明老屋位置。老屋興建年、文史館開館日、營運單位均未查到（維持 PENDING）。
- 文史館是現代設施，位置與年代掛在「老屋新生」，與人物活動年代是兩件事。

## 6. 年代對照（重點）

| 項目 | 年份 |
| --- | --- |
| 生 | 1850 |
| 遷居大稻埕 | 1882 |
| 活動高峰（執照、區長、改革會、赴日） | 1897–1917 |
| 卒 | 1918 |
| 遊戲「庶民生活」 | 1945–1980 |

- **黃玉階的活動全在 1850–1918，比庶民生活年代早 27 年以上結束。庶民生活年代他不在世，沒有任何關於他在 1945 年後的記載。**
- 他的活動與「港口商街」（1853–1895）後段（1882 遷居）及「酒樓繁華」（1895–1930）前半段重疊，主體在**酒樓繁華**（日治初期，1895–1918）。
- 1945 年以後與他有關的只可能是：至善堂（戰後狀態**查無**）、文史館（2000 以後，老屋新生）。**不能用「至善堂」推論戰後的黃玉階故事**。專案 PENDING 已列：臺灣記憶的至善堂是否即豆花店介紹提到的財團法人台北市至善堂，未核實。

結論：**黃玉階不適合放進「庶民生活」，人物活動不在本年代**。

## 結論

**對「庶民生活」：資料不足，不做（人物活動不在本年代）。**
**對人物本身：部分可做**——在**酒樓繁華**（日治初期）的純文字小節可行，但目前沒有掛載點（酒樓繁華已有蔣渭水；黃玉階文史館在老屋新生，故事已寫「黃玉階與大稻埕」「社會改革與教育」三章，內容與本紀錄一致）。

可做章節方向（擇一，需使用者決定）：
1. **維持現狀**：人物已由文史館的三章承擔（老屋新生）；庶民生活年代另覓人物或標「在地經營者群像」。
2. **補一段在「酒樓繁華」**：不新增店家，在既有故事末加「疫病與社會改革」小節（1897 鼠疫 → 執照 → 區長 → 天然足會、斷髮不改裝會）；掛載到哪個故事需另行選定（候選：江山樓或第 3 階段的某個日治初期故事，**未決**）。

必須標「待核」：卒日、執照年（並列 1897／1901）、1872 北上、中法戰爭、教誨師與一新舍、赴日名目、至善堂年份與現址、女子分校。
不寫：議員、住所門牌、黃瑤琨親屬、戰後至善堂、療法效果、政治或歷史評價、稱號（如「列紳第一人」只見論文題名，不採為稱號）。
要先補的來源：臺灣大百科條目、施建仁論文全文、北藝大「至善堂」報告書、《臺灣日日新報》1918 訃告。
