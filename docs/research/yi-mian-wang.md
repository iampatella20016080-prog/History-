## 4. 能否做成「米苔目主題」的另一個版本

先看現有做法（`src/data/miTaiMuLayout.js`）：主題 `mi-tai-mu` 的 `versions` 已有兩個年代版本——`postwar`＝慈聖宮廟埕的米苔目攤（情境示意，不是特定店家）、`revival`＝永樂米苔目現代店面（實地照片建模）。註解已明寫「兩者只以飲食主題串連」。

- **主題不符**：意麵王賣的是乾意麵與餛飩湯（S1），不是米苔目。把它放進米苔目主題的 `versions` 會把兩種不同的麵混為一談。
- **年代位置已滿**：`versions` 以年代 id 為鍵，`postwar`、`revival` 皆已被占用；意麵王若創立於 1938，唯一對得上的是 `modern`（1930–1945），但 1938 本身沒有出處（見第 1 節），且戰前店面型態、位置全部查無。
- 就算當作「意麵／麵食」新主題：只有現代食記可用，缺少任何可寫成歷史的內容。
