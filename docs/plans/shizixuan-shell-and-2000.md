| 截圖裡的現象 | 程式碼裡的原因 |
| --- | --- |

| 1945 從高處看，屋頂下有一圈縫 | `postwarShop()`：平屋頂放在 `wallH + 0.9`，側牆與後牆只到 `wallH`，女兒牆只有正面一片，所以三面都留下 0.9 m 的縫。 |
| 2000 整棟像 dollhouse，看得到紅磚與天花梁 | `modernShop()`：二、三樓**完全沒有正面牆**，只有腰帶與 `rectWindow`。側牆與後牆用了 `brick` 材質，才會看起來是紅磚。也沒有樓板，室內天花的木格柵從外面看得到。 |

## 1. 共用的殼體工具（新檔）

`src/game/builders/shizixuan/shizixuanShell.js`

```js
export function buildShell(b, { half, depth, wallT, inset = 0.012, frontZ = 0, heights, mat, tint, sideTint, openings, parapet })
```

規則：

- **側牆**往內退 `inset`（約 1.2 cm），外側不和隔壁的山牆共面。左右側牆是 party wall，一律蓋到屋頂或女兒牆頂。
- **正面牆與後牆**只蓋在兩道側牆之間（`x ∈ [−half + inset + wallT, half − inset − wallT]`），不和側牆重疊，頂面也不共面。
- 正面牆用「開口清單」建立：`openings: [{ minX, maxX, minY, maxY }]`。牆依開口切成水平帶與垂直段（窗下、窗間、窗上），**窗戶嵌在牆的開口裡**。不要再用「整面窗框、後面沒有牆」的做法。
- 每一層樓都有**樓板**（厚度 0.15 m，放在每層頂部）。屋頂板放在牆頂下 0.05 m，蓋在四面女兒牆裡面。
- 回傳 `shellParts = { front, back, left, right, floor, roof, slabs: [...] }`。每一項是這次建立的方塊範圍（建築本地座標），給測試檢查用。
- 樓上沒有室內的部分，在窗戶後面 0.3 m 放一片暗色的室內背板（`interior` 或 `dark` 材質），上下接樓板、左右接側牆。從窗戶看進去是暗的室內，不是空洞或後面的街景。
- 已經在牆面上的薄飾件（腰帶、窗台、招牌底板）一律**往外偏移至少 1 cm**，不和牆面共面。招牌文字仍然用 `addSign`（貼花例外）。
- **不要**用 `polygonOffset`／`depthTest:false`／`renderOrder`／`transparent` 修共面。

## 2. 1930 `earlyShop` 殼體修復（外觀不改風格）

`shizixuanExterior.js` 的 `earlyShop()`：

1. 正面牆改用 `buildShell`。一樓開口：門與兩扇展示窗。二樓開口：一扇 0.9 × 0.9 m 的窗，窗下 `groundH + 0.35`。二樓窗嵌進牆裡，外面套木框，後面是暗色背板。
2. 側牆蓋到屋簷：`wallH`。兩側再各加一片**三角形山牆**，用 `Shape` 加 `b.extrude('brick', …)`，從 `wallH` 往上到屋脊，前後頂點對齊屋頂。
3. 屋頂照幾何計算：`slope = atan(rise / (depth / 2))`，每片長度 `hypot(depth / 2 + overhang, rise)`，`overhang = 0.4`。兩片在屋脊相接，加一條屋脊蓋（box）。屋頂寬度 `half * 2 − inset * 2`，**不超出地段**。屋簷只往前後伸出，不往左右伸出。
4. 二樓樓板放在 `groundH`。這個高度也是一樓室內的天花（`interiors[0].ceiling` 維持 `groundH`）。
5. 前舖與後坊之間的隔牆蓋到二樓樓板（現在只有碰撞，沒有牆）。

## 3. 1945 `postwarShop` 殼體修復

1. 四面牆一律蓋到 `wallH + parapet`（`parapet = 0.9`）。屋頂板放在 `wallH`，四面都有女兒牆。
2. 正面二樓三扇窗嵌進牆的開口裡，窗後放暗色背板。
3. 二樓樓板放在 `groundH`。
4. 天井只保留一個**封閉的玻璃天窗盒**（玻璃頂加四邊矮牆），不是透光的空洞。
5. 側牆往內退 `inset`，和右側冰果室（north-4）的山牆不共面。

## 4. 2000 `modernShop` 全面重做（以使用者的實拍照片為準）

### 4.1 外觀（照片：延平北路二段68號）

- **量體**：三層樓加平屋頂。`groundH = 3.4`，`upperH = 3.0`，女兒牆 0.6 m。樓上立面**懸挑到騎樓外緣**（`z = 1.7`），一樓店面退在 `z = 0`。也就是標準的騎樓形式，和 `arcade.js` 的一般騎樓街屋一致。
- **立面材質**：淡米黃小磁磚，用 `creamTile` 材質，tint 約 `#e8d8a8`，磁磚縫靠材質貼圖表現。**不用 `brick`**。側牆與後牆用同色系的 `plaster`。
- **兩個開間**：中央一道寬 0.6 m 的柱（從地面到女兒牆，略凸出 3 cm），兩端各一道邊柱。
  - 左開間每層三扇等寬窗。
  - 右開間每層三扇窗，寬度是窄、寬、窄。
  - 窗都在牆的開口裡，四周退縮 8 cm 形成窗洞的深度。
  - 木色窗框（`wood`，`#9a6a3a`），格子窗櫺。窗的下三分之一是黑色鐵窗花，有欄杆感。
  - 窗後是暗色室內背板，部分窗戶用 `windowLit`，是暖光的室內。
- **一樓**：左開間是大面積展示玻璃，右開間是主入口玻璃門（`glassStorefront`），木色直框。玻璃後面看得到亮燈的商品架。騎樓天花是白色，有嵌燈（glow）。中央柱前放一個灰色電箱，加黃黑警示條。
- **招牌**（新增招牌樣式，見 §6）：
  - 左開間上方是紅色招牌盒，中央是金色圓形「十」字紋樣的徽章，下方小字「TEN CAKE」「SINCE 1930」。
  - 右開間上方是紅色招牌盒，金色圓框單字「十字軒糕餅舖」，下方小字「SHI ZI XUAN CAKE & PASTRY」。
  - 右側立面外是紅色直式招牌，圓框「十字軒」加徽章，用支架固定在柱上。
  - 招牌盒是有厚度的盒子（深 0.3 m，黑色邊框），文字用 `addSign` 貼在盒子正面，往外 1 cm。
- **屋頂**：平屋頂，四面女兒牆，屋頂上有幾個盆栽與綠籬（照片裡屋頂的樹），用既有的 `planter`／`pottedPlant`。
- **街景**：騎樓邊停 3–4 台機車（沿用現有的 `scooter()`）。
- **移除**：全部紅磚、傳統瓦屋頂、木板招牌、裸露木構、深紅照明。

碰撞：騎樓可以行走，三道柱是障礙物，入口只在右開間。左開間是展示窗，不能穿越。

## 7. 幾何檢查（新增測試 `tests/shizixuanShell.test.js`）

在 PartBuilder 上攔截 `add`（`tests/flicker.test.js` 的做法），只收集十字軒這棟建築的零件。三個年代都要檢查：

1. **shellParts 完整**：`front`、`back`、`left`、`right`、`roof`、`floor`、每一層的 `slabs` 都存在，而且範圍覆蓋整個面。
2. **封閉殼體（射線檢查）**：
   - 用 three.js `Raycaster`（Node 可以用），從建築外 8 個方向（前、後、左、右、四個斜角）與上方，在格點上往建築中心發射射線。
   - 高度從 0.3 m 到屋脊，每 0.4 m 一點。
   - 每一條都必須在到達中心前打到殼體。正面的門、窗開口另外列為允許穿過的區域：打穿開口的射線之後必須打到室內背板或室內牆。
   - 樓上的窗：射線必須在 0.5 m 內打到背板。
3. **共面重疊**：任兩個零件的平行外表面，距離 < 2 mm 而且投影重疊面積 > 1 cm² 就算失敗。招牌的 `addSign` 不是零件，不算在內。
4. **屋頂不穿入鄰棟**：屋頂零件的 x 範圍必須在 `[site.x − half, site.x + half]` 內。屋簷只能往 ±z 超出，最多 0.6 m。
5. **側牆不和鄰棟共面**：側牆外表面與地段邊界的距離 ≥ 5 mm。
6. **既有測試照常通過**：`tests/shizixuan.test.js`（碰撞、熱點、五個節點）、`tests/yongle.test.js`、`tests/riceAndShine.test.js`。
7. **2000 的家具間距**：任兩個家具範圍之間 ≥ 1.1 m，或貼牆、或彼此相接。從入口出發，能走到每一個熱點前（用既有的 `walkTo` 測試）。
8. **頂點預算**：2000 室內主網格 ≤ 130k，細部 ≤ 70k。外觀主網格 ≤ 60k。

## 11. 風險

| 風險 | 處理 |
| --- | --- |
| 樓上立面懸挑到騎樓上方以後，騎樓裡的跟隨鏡頭可能被遮擋方塊擋住 | 參考 `arcade.js` 一般騎樓的遮擋高度（只擋 `groundH − 0.65` 以上），用既有的跟隨鏡頭測試驗證 |
| 商品太多，頂點超過預算 | 細節放 `detail`；遠處的層架用較少面數的形狀 |
| `tests/yongle.test.js` 的逐頂點檢查 | 2000 改成騎樓懸挑以後仍然在 `inShizixuanLot` 範圍內（`z` 上限 2.0），不用改 |
| 遇到重大架構問題，或同一個問題修三次還失敗 | 停下來，回報給 Opus 分析 |
