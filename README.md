# 大稻埕食光街：走進170年的飲食記憶

以第三人稱 3D 探索遊戲的方式走進大稻埕：玩家扮演一位旅人，在街道中漫步、走近具有歷史意義的店家，透過店家與食物理解大稻埕的歷史、經濟與社會變遷。

> 目前為 **第一階段**：1853–1895 年「港口商街」的一小段街區，開放一間互動店家「林復振」。

## 第一階段內容

- **3D 街景**：一條可行走的主街、兩側連續的閩南式街屋（紅磚、灰泥、木門板、木格窗、亭仔腳屋簷、人字／馬背山牆、燕尾脊）、木箱、茶箱、麻布袋、乾貨籃等擺設；街尾通往河岸廣場與碼頭，遠方是淡水河、戎克船與觀音山意象。
- **畫面風格**：低多邊形建模、卡通渲染（cel-shading）、細黑輪廓線、低飽和復古配色、程式產生的手繪感貼圖、遠景柔焦與分層遠山。
- **角色操作**：WASD／方向鍵移動、Shift 快走、角色依方向轉身並有行走動畫；鏡頭平滑跟隨，可拖曳旋轉、滾輪縮放，遇到建築會自動拉近避免穿牆；角色不能穿過建築，並有街道邊界。
- **互動店家「林復振」**：走近時店面上方浮現提示，按 **E** 後角色停下、鏡頭移到店面，開啟紙張質感的介紹視窗（大稻埕的形成／林復振的歷史／代表食物圖鑑／文獻與歷史依據），點「關閉」或按 **Esc** 返回街道。
- **介面**：左上標題、上方年代橫幅、右上店家選單（可「前往店門口」或直接「閱讀故事」）、操作說明與任務提示。

## 執行方式

需要 Node.js 20.19 以上（或 22.12 以上）。

```bash
npm install
npm run dev       # 開發模式，開啟終端機顯示的網址（預設 http://localhost:5173）
npm run build     # 打包到 dist/
npm run preview   # 預覽打包結果
```

打包使用相對路徑（`base: './'`），`dist/` 可以直接部署到 GitHub Pages 等靜態網站空間。第一版以桌面瀏覽器（支援 WebGL 2）與鍵盤操作為主。

## 新增店家

所有店家共用同一套互動提示、鏡頭運鏡與介紹視窗。新增店家時只需在 `src/data/shops.js` 加入一筆資料：

```js
{
  id: 'example-shop',
  name: '店名',
  eraId: 'qing-port',            // 對應 eras.js
  year: 1869,
  category: '茶行',
  seal: '茶行',                   // 介紹視窗的印章文字
  summary: '一句話介紹（顯示在選單）',
  position: { x: 14, z: 4.5 },   // 店面立面中心座標；南側街屋 z = 4.5、北側 z = -4.5
  facing: 'north',               // 店面朝向
  interaction: { radius: 3.4 },
  building: {                    // 交給共用的街屋產生器
    type: 'shophouse', width: 6, depth: 11, floors: 2,
    ground: 'brick', upper: 'plaster', gable: 'horseback', ridge: 'curved',
    storefront: 'open',
    sign: { text: '店名', style: 'lacquer' },
    display: ['dried-goods'],
  },
  camera: { distance: 7.6, height: 4.6, side: 11, lookHeight: 3.6 },
  chapters: [ /* type: 'text' | 'foods' | 'sources' */ ],
}
```

街景會自動在該座標預留店面並補齊兩側街屋。需要不同形式的建築（市場、酒樓）時，在 `src/game/world/buildWorld.js` 的 `BUILDING_BUILDERS` 註冊新的產生器，並以 `building.type` 指定。食物圖鑑插圖在 `src/ui/FoodIllustration.jsx` 依食物 id 新增。

## 卡通渲染管線

`src/game/rendering/ToonRenderer.jsx` 接管 R3F 的渲染：

1. 以法線材質覆寫整個場景，取得法線與深度
2. 正常渲染彩色畫面（`MeshToonMaterial` 階調光影、陰影）
3. 依深度（1/z 的二階差分）與法線差異描出細黑輪廓線，遠處線條自然淡出
4. 遠景柔焦、溫和色調映射、暗角與紙張顆粒，最後輸出 sRGB

整條街依材質合併成少數網格，每影格約兩百次繪製呼叫。

## 歷史內容與文獻

- 店家介紹整理自：中央研究院臺灣史研究所檔案館，〈林復振商行〉。<https://archives.ith.sinica.edu.tw/collections_con.php?no=134>
- 食物圖鑑中標示「文獻小記」者出自上列文獻；其餘為南北貨品項的一般介紹，並非林復振的實際貨品清單。
- 背景街屋的招牌只使用「茶、米、布」等一般行業字，不虛構具名商號。
- 3D 街景為 19 世紀大稻埕商業街區氛圍的概念性重建，並非精確復原。
